# 宜北高中第二版｜免費架站原型 v0.3

這是**可執行的第一階段網站原型**，不是完整遊戲。正式開局為林清源先推送玩家微信給付彬言，玩家手動接受付彬言的好友申請。測試版告白等事件不會匯入。

## 已實作
- 手機鎖定畫面與桌布、微信聊天列表、通訊錄、好友申請
- 首次必填自訂暱稱、序章前言、人物關係介紹（可供新玩家閱讀）、基本 Gemini API 回覆（有金鑰才啟用）
- 朋友圈純文字貼文、按讚、留言、基本 NPC 示範動態
- 玩家姓名修改、瀏覽器本機存檔、JSON 匯出與匯入
- 今日行程／現實場景介面示意
- 八張經玩家指定的原始頭貼（七位 NPC＋玩家預設）；玩家可自行上傳、還原頭貼並隨 JSON 存檔保存

## 尚未完成（請勿誤認已具備）
- NPC 自主邀約的完整動機判斷、完整長期記憶與各角色知情隔離
- 真正的離線事件補算、行程衝突檢查、期限事件處理
- AI 多人群聊、實際線下場景的互動引擎
- 所有歷史台詞逐字整合進檢索系統（企劃書附於 docs/，但尚未全部程式化）

## 本機啟動
1. 安裝 Node.js 18 以上
2. 在專案目錄執行 `npm start`
3. 瀏覽 `http://localhost:3000`

## GitHub + Render Free
1. 建立新的 Private repository `yibei-high-school-v2`，上傳本 ZIP **解壓後的檔案**（不是直接把 ZIP 當成唯一檔案）。
2. Render 新增 Web Service，連接此 repository。
3. Runtime 選 Node，Build Command 可留空或 `npm install`，Start Command 設 `npm start`。
4. 在 Render Environment 加入 `GEMINI_API_KEY`（**只放在 Render 環境變數，不要寫入 GitHub**）。
5. 可選 `GEMINI_MODEL`，預設 `gemini-2.5-flash`；模型可用性及免費額度需以自己的 Gemini 專案為準。
6. 部署後開啟 Render 提供的網址。

## 資料注意
- 存檔目前使用 localStorage（不是先前規劃的 IndexedDB），只保存在同一瀏覽器。清除瀏覽器資料會遺失；請定期匯出 JSON。
- 本原型沒有帳號登入或跨裝置同步。請勿在公用裝置輸入敏感資訊。
- AI 的回覆品質、額度、模型可用性尚未經完整測試。未設定 API 金鑰時，系統會明確提示，**不會假裝 NPC 已由 AI 回覆**。
- 部署到 Render 的 API 金鑰只能存在後端環境變數，不得放在 `public/`。
